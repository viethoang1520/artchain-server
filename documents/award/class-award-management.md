# Awards Controller

**Prefix:** `api/awards`

| No  | Method              | Description                           |
| --- | ------------------- | ------------------------------------- |
| 1   | `createBatch()`     | Create multiple awards at once        |
| 2   | `findAll()`         | Get all awards                        |
| 3   | `findByContestId()` | Get all awards for a specific contest |
| 4   | `findOne()`         | Get award by ID                       |
| 5   | `update()`          | Update an award                       |
| 6   | `remove()`          | Delete an award                       |
