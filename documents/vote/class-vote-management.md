# Votes Controller

**Prefix:** `api/votes`

| No  | Method                   | Description                                              |
| --- | ------------------------ | -------------------------------------------------------- |
| 1   | `getVotableAwards()`     | Get votable awards in a contest                          |
| 2   | `getPaintingsForAward()` | Get Round 2 paintings votable for a specific award       |
| 3   | `voteForAward()`         | Vote for a Round 2 painting in a specific award category |
| 4   | `removeVoteForAward()`   | Remove a vote                                            |
