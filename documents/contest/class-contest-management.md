# Contests Controller

**Prefix:** `api/contests`

| No  | Method                 | Description                                                 |
| --- | ---------------------- | ----------------------------------------------------------- |
| 1   | `findAll()`            | Get all contests with pagination and optional status filter |
| 2   | `findAllForExaminer()` | Get contests assigned to a specific examiner                |
| 3   | `findOne()`            | Get contest by ID                                           |
| 4   | `checkUploadStatus()`  | Check if users have uploaded paintings for Round 1          |
