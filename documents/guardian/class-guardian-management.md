# Guardians Controller

**Prefix:** `api/guardians`

| No  | Method                       | Description                                        |
| --- | ---------------------------- | -------------------------------------------------- |
| 1   | `assignStudentToGuardian()`  | Register competitors and assign them to a guardian |
| 2   | `getStudentsByGuardian()`    | Get all competitors assigned to a guardian         |
| 3   | `getCompetitorSubmissions()` | Get submissions of a specific competitor           |
