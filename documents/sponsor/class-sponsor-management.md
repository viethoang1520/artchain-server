# Sponsors Controller

**Prefix:** `api/sponsors`

| No  | Method             | Description                                            |
| --- | ------------------ | ------------------------------------------------------ |
| 1   | `getAllSponsors()` | Get all sponsors with optional status filter           |
| 2   | `getSponsorById()` | Get sponsor detail by ID                               |
| 3   | `createSponsor()`  | Create a new sponsor with logo upload and payment link |
